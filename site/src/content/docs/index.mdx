## 关于这本书

这本书只讲一件事：怎么用 Phoenix 1.7 把一个真实应用从零搭起来。不是 Hello World 教程，
是一个**拍卖网站**——能列商品、出价、登录、实时推送新出价，还有一套给外部程序用的 JSON API。

仓库里的每个章节目录是一个**可运行的代码快照**，不是"示例片段"：每章对应的 `chXX/` 目录
都能 `mix phx.server` 起服务、`mix test` 全绿。讲法是先打开代码，再解释它为什么长这样。
